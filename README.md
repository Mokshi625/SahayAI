# SahayAI – AI Government Scheme Assistant 🇮🇳

SahayAI is an AI-powered, multilingual assistant designed to help citizens of India easily discover, understand, and access government welfare schemes. It focuses on inclusion, accessibility, and simplicity, especially for users with limited digital literacy or language barriers.

This project is developed as part of the **Hack2Skill – AI for Bharat Hackathon**.

---

##  Problem Statement

Accessing government schemes in India is often difficult due to:
- Language barriers
- Complex eligibility criteria
- Scattered information across portals
- Low digital literacy
- Lack of awareness in rural and underserved communities

SahayAI aims to bridge this gap using AI.

---

##  Solution Overview

SahayAI acts as a **voice-first and text-based AI assistant** that:
- Supports multiple Indian languages
- Understands natural, conversational queries
- Matches users with relevant government schemes
- Explains eligibility, benefits, and application steps in simple language
- Works across platforms like mobile apps and WhatsApp

---

##  Key Features

-  Multilingual support for major Indian languages  
-  Voice and text-based interaction  
-  Personalized scheme recommendations  
-  Location-specific scheme awareness  
-  Privacy-focused user profile management  
-  WhatsApp and mobile app integration  
-  Low-bandwidth and accessibility-friendly design  

---

##  Architecture

The system follows a **microservices-based, cloud-native architecture** with:
- API Gateway
- NLP-based query processing
- Speech-to-text and text-to-speech modules
- Recommendation engine
- Government API integrations (API Setu, state portals)

Detailed architecture and correctness properties are described in `design.md`.
